# RC-RefGS Geometry Diagnostic Fields Plan - 2026-06-05

## Objective

Add future non-invasive diagnostics that explain whether RC correspondences are geometrically valid before introducing any geometry-aware loss.

## Recommended Flags

- `--log_rc_geometry_diagnostics`
- `--rc_geometry_diagnostics_interval`
- `--rc_geometry_diagnostics_output`

Defaults must preserve existing behavior exactly.

## Fields To Log

- RC valid correspondence ratio
- pair-angle distribution
- reflection-direction similarity distribution
- confidence-weight distribution
- reflective-mask coverage
- specular variance
- depth-valid ratio
- normal-valid ratio
- normal agreement distribution if normal buffers exist
- reconstruction residual distribution inside RC-valid regions

## Implementation Boundary

Do not add loss terms in this diagnostic step. Log only when explicitly enabled. Keep existing base/rc/ablation/qp variants unchanged.

## Required Tests

- Default `train.py` path unchanged.
- Diagnostics disabled by default.
- Output path is explicit and does not overwrite existing experiment roots.
- No Shiny Blender Real scope is generated by diagnostic runners.
- Raw Glossy Synthetic is never used as a train source.
